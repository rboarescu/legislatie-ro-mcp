# Dicționar de Mapare: Limbaj Uzual / Situații din Documente $\rightarrow$ Acte Normative & Instituții Juridice

Acest ghid de referință ajută AI-ul să traducă rapid problema exprimată de un utilizator fără studii juridice (sau elementele dintr-un document încărcat) în **actele normative oficiale din `legislatie.just.ro`** și **cuvintele-cheie exacte** pe care trebuie să le caute.

> **Atenție:** numerele de articole de mai jos au fost verificate pe forma consolidată din `legislatie.just.ro` la **22.10.2026**. Ele sunt doar puncte de plecare pentru căutare: legile se modifică și se renumerotează, deci **extrage întotdeauna textul cu unealta** înainte de a-l cita. Scrie actele cu tip, număr și **an** (ex: `HG 859/2021`), altfel căutarea poate fi ambiguă.

## 6. Vocabularul legii pentru căutare (limbaj uzual $\rightarrow$ termenii din text)
Căutarea în act găsește doar cuvintele care apar efectiv în lege. Dacă o căutare nu întoarce nimic, reformulează cu termenii legii:

| Limbaj uzual | Termeni folosiți de lege |
| :--- | :--- |
| dronă, drone | aeronave fără pilot (la bord), UAS |
| filmare / poze din aer, topografie aeriană | fotografiere, filmare, cartografiere |
| amendă | sancțiune contravențională, amendă contravențională |
| primărie (ca autoritate) | unitatea administrativ-teritorială, primarul, consiliul local |
| dat afară | concediere, încetarea contractului individual de muncă |
| a-mi da demisia | demisie, termen de preaviz |
| chirie, chiriaș | locațiune, locatar, contract de închiriere |
| a contesta în instanță un act al primăriei | plângere prealabilă, acțiune în contencios administrativ |
| întârziere la întreținere | restanță, penalități de întârziere |
| intabulare, extras CF | înscriere în cartea funciară, încheiere |
